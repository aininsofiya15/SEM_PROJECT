# Final Year Project Supervisor Hunting Application (FYPSHA)

A web-based application developed to help students find and apply for suitable Final Year Project (FYP) supervisors based on their research interests and project requirements.

## 📌 Project Overview

The Final Year Project Supervisor Hunting Application (FYPSHA) was developed as part of the Software Evolution and Maintenance course.

The system provides a platform for students to explore available supervisors, manage project topics and titles, and submit FYP supervisor applications.

This project focused on applying software evolution and maintenance practices to improve the existing system.

## 🛠️ Technologies

- PHP
- Laravel
- MySQL
- JavaScript
- HTML
- CSS
- Git & GitHub

## ✨ Key Features

- Student registration and authentication
- Supervisor management
- Research area management
- Topic and title application
- FYP supervisor application management
- Database management
- Input validation
